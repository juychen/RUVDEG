# Publicdata benchmark — per-celltype batch-distance summary

Generated by `plot_benchmark_pubdata_bars.py` from summary CSVs in
`/data8/junyi/benchmark_results_pubdata/<DATASET>_<MODEL>/`.

## Source data

Summary CSV columns: `celltype, batch_A, batch_B, layer, metric, n_genes, mean_d, median_d`

- **Layers**: `raw` (uncorrected), `corr` (post-correction). All plots use `corr`.
- **Metrics**: `cohens_d`, `hellinger`, `mean_diff`, `var_ratio`.
- **Aggregation**: per `(celltype, metric)` we average `mean_d` over batch pairs
  (SEM = sd / sqrt(n_pairs)). Per-dataset summary chart averages further
  across cell types; the fourth panel averages across 3 scale-comparable metrics
  (excluding `var_ratio`, whose values span 1e0–1e6).
