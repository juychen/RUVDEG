# Publicdata benchmark — per-celltype batch-distance summary

Generated by `plot_benchmark_pubdata_bars.py` from the summary CSVs in
`/data8/junyi/benchmark_results_pubdata/<DATASET>_<MODEL>/`.

## Source data

Summary CSV columns: `celltype, batch_A, batch_B, layer, metric, n_genes, mean_d, median_d`

- **Layers**: `raw` (uncorrected) and `corr` (post-correction). All plots use `corr`.
- **Metrics**: `cohens_d`, `hellinger`, `mean_diff`, `var_ratio`.
- **Aggregation**: for each `(celltype, metric)` we average `mean_d` over batch pairs
  (SEM = sd / sqrt(n_pairs)). For the per-dataset summary chart we average further
  across cell types (and a fourth panel averages across the 3 scale-comparable metrics
  excluding `var_ratio`, which spans 1e0–1e6).

## Per-metric takeaway (corr layer, lower = better unless noted)

- **Cohen's d** (more negative = better): `scVI` wins on GSE118767; all three
  perform similarly on GSE133549.
- **Hellinger distance**: tight across models; `scVI-Harmony` is marginally
  best on both datasets.
- **Mean diff** (small): `scVI-batch` is best on GSE118767; `scVI-Harmony`
  is best on GSE133549.
- **Variance ratio** (closer to 1 = better; log-scaled): `scVI-batch` is best
  on both datasets. `scVI` overshoots by 1–2 orders of magnitude on GSE133549.
- **Mean of 3 scale-comparable metrics**: `scVI-batch` and `scVI-Harmony` are
  within ~1% on GSE118767; on GSE133549 the gap widens to ~25% in favour of
  `scVI-Harmony` (but `scVI-batch` wins on var_ratio).
